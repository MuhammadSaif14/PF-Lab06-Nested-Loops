# PF Lab 06 – Nested Loop Tasks

This repository contains my solutions for **Lab#06** of the course **CL-1002 Programming Fundamentals** (FAST-NUCES, Fall 2026), taught by Sir Muhammad Aais Rabbani.

All programs are written in **C** and use nested loops to print patterns and solve number problems (`math.h` is not used).

## Programs Included
1. **Two Star Triangles** – prints a downward-aligned and an upward-aligned star triangle using nested `for` loops.
2. **Symbol Arrow** – prints an arrow pattern using any symbol entered by the user.
3. **Exponential Series** – computes the series `sum of x^k / k!` from k = 0 to n, calculating powers and factorials with loops.
4. **Perfect Numbers** – displays the first 4 perfect numbers along with the sum of their divisors.
5. **Symbol Pyramid** – prints a pyramid with the number of rows and symbol chosen by the user.
6. **Number Diamond** – prints a diamond pattern of numbers for the given number of rows.

## How to Run
```bash
gcc filename.c -o output
./output
```
